NEXUS OS - ORIGINAL KERNEL

Most operating systems grew by adding. Nexus started by choosing: a kernel small enough to read, an installer that can’t wipe the wrong disk, and nothing running that you didn’t start.

    Small by design. Complete by default.

    Everything here is in the prototype build of 24 November 2026.

        Questions

        Is Nexus based on Linux?

        No. The kernel, scheduler, memory manager, filesystems, drivers and installer are original. It uses the open-source Limine bootloader only to get started.

        Will Nexus replace my current OS?

        Not on day one. Until it runs more apps and opens HTTPS sites, use it on a spare PC or in a virtual machine next to your main system.

        Can I run my existing apps?

        No. Nexus loads its own ELF64 programs in user mode, with a 128 KiB size limit in this prototype.

        Does the browser support HTTPS?

        Not yet. It fetches plain HTTP text pages and runs no scripts.

        How do I try it?

        Boot the ISO in a virtual machine or from a USB stick. Nothing is written to a disk until you confirm in the installer.

        Is my data safe during install?

        The installer checks the boot media, asks twice and keeps a recovery journal. Back up anything important before installing any new OS.
